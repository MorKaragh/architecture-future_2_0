# Доменная модель и событийная архитектура

Материалы фиксируют разбиение экосистемы на домены и bounded contexts, ключевые агрегаты, каталог доменных событий и целевую событийную схему в нотации, близкой к Event Storming. Обоснование выбора событийного взаимодействия относительно текущей шины Apache Camel и DWH — в отдельном файле.

## Состав каталога

| Файл | Содержание |
|------|------------|
| [bounded-contexts.md](bounded-contexts.md) | Карта bounded contexts, интеграционные отношения (контекстная карта), таблицы для визуализации |
| [event-storming.md](event-storming.md) | Поток команд и доменных событий, издатели и подписчики |
| [aggregates.md](aggregates.md) | Агрегаты: границы, инварианты, идентификаторы |
| [events.md](events.md) | Каталог событий и минимальные контракты |
| [justification.md](justification.md) | Событийный подход против точечных интеграций через Camel и централизации логики в DWH |

Исполняемого кода в каталоге нет. Диаграммы в markdown можно открыть в просмотрщике с поддержкой Mermaid или экспортировать в PNG через стандартные инструменты сборки документации.
